# 翼测通 / Jice Tong

**An offline, source-verifiable academic record Skill for Chinese university students — three ledgers, one rule book, zero guesses.**

翼测通把高校的**培养方案、综测细则、推免办法**读成三本能算的账：

1. **学分账**——还差多少学分毕业、哪些课没排进学期；
2. **综测账**——每一项加多少分、有什么限制、扣多少；
3. **推免账**——同一张奖状在推免体系里值多少。

核心发现：**综测与推免是两套独立的分**。同一张「省甲类竞赛全国一等奖、队内第 1 名」，综测给 10 分，推免给 20~50 分——**差 5 倍**，且分级口径完全不同（六级直接给分 vs 四类乘系数）。拿综测的表查推免分，一定会算错。

## What it does · 它做什么

1. **读文件**：PDF / Word 里的课程表与条款解析成结构化规则，每条带原文页码 / 条款号。实测重庆邮电大学智能科学与技术培养方案 13 页 → 抽出 103 门课（必修 49 门 / 120.5 学分）。
2. **算三账**：综测按「基础分 + 附加分封顶 − 扣分」计算；绩点按课程成绩三级加权；推免按八类加分与系数计算。公式全部可见、可手算复核。
3. **能溯源**：综测细则 505 行、推免办法 359 行全文内嵌 HTML。点每条分值的「来源」，直接跳到对应那一行并高亮——不是印一个点不开的文件名。
4. **材料档案**：奖状 / 证书原图存本机 IndexedDB，离线抽取级别、等级、队内排序，匹配细则给出建议分；「待核」一律计 0，确认后才计入账本。
5. **排任务**：按学期生成制度上必须做的事，每条带依据与不做的后果；一次最多 6 件，按课程 > 外部规则 > 分类缺口排序。

## Design principles · 设计原则

1. **必须溯源**：每条数据带原文坐标，核不到就留空。
2. **溯源必须点得开**：内嵌全文，点击跳转并高亮到具体条款。
3. **不编造**：文件没写的一律「不知道」；文件自相矛盾就两个都报出来，指出去哪里问。
4. **数字逐字来自原文**：原文写 2.5 就写 2.5；绩点换算规则不在培养方案里，就用明确标注「示例」的规则垫底，并引导上传《学生手册》替换。

## Privacy & limits · 隐私与边界

1. **全部计算在本机完成**：技能不联网、不上传任何文件、分数或结论。
2. **四个脚本零第三方依赖**：只用 `json` / `re` / `sys`。
3. **单文件 HTML 离线可用**：168 KB，双击即开，不需要服务器。
4. **不做**：查成绩、连教务系统、识别扫描件、承诺获奖、替学院认定、建全国大库、编截止日期。
