# 冀测通 · 学业记录（jice-tong）

## 这个技能解决什么

一本账，管四件事：

| 部分 | 回答 | 时间尺度 | 输入 |
|---|---|---|---|
| **四个年级板块** | 大一到大四，各年综测多少、哪块还差 | 每学年 | 综测实施细则 |
| **绩点账** | 每门课期末+平时各占多少、加权平均多少 | 每学期 | 用户录入 + 教师评分规则 |
| **材料档案** | 这张奖状/这次打卡算哪块、值多少分 | 随时 | 奖状、证书、打卡记录 |
| **毕业账 / 推免账** | 还差多少学分；同一件事在综测和推免两边分别值多少 | 四年 / 大三下 | 培养方案、推免办法 |

**关键洞察一：综测和推免是两套独立的分值体系。** 同一张省甲类竞赛全国一等奖，综测给 10 分，推免按 A1/A2/B/其他系数给 50/40/20/10 分，**差 5 倍**。

**关键洞察二：绩点不是综测。** 综测的「智育」用 `∑(课程成绩×学分) ÷ ∑课程学分`（加权平均分），绩点是学校另一套换算。**两列并排显示，各标用途**，不要拿 GPA 去乘 70%。

## 核心工作流

### 第一步 · 建档案（首访三件事）

1. **问基本信息**：学院 / 专业 / 入学年份 / 当前年级（姓名学号可选，且只存本机）。**一次只问一组**，不要一口气列十个问题。
2. **读培养方案**：判断类型（文本 PDF / 扫描件 / Word·Excel）→ 抽学分明细 + **逐门课程表**（课程号 / 课程名 / 学分 / 学时 / 考核方式 / 开课学期 / 必修选修）。
3. **确认后落账**：把课程按「学期 1-2 → 大一、3-4 → 大二、5-6 → 大三、7-8 → 大四，单数上、双数下」分进四个年级，**分数留空**，等用户逐门填。

**没给文件就先用内置方案**：重庆邮电大学人工智能学院·智能科学与技术（13 页，已抽出 103 门课 / 必修 49 门 / 120.5 学分）。用户是别的学院时，让他粘贴一份课程表（一行一门：课程名 学分 学期 必修/选修），按规则识别，**识别不出学分的行标「待确认」且默认不导入**。

### 第二步 · 录课程（绩点账）

每门课拆成**期末 + 平时**两层：

```
平时分   = ∑(条目得分 × 条目权重) ÷ ∑条目权重      ← 权重不必凑 100，按比例折算
课程成绩 = 期末分 × 期末权重% + 平时分 × (1 − 期末权重%)
加权平均 = ∑(课程成绩 × 学分) ÷ ∑学分             ← 综测细则（二）原文公式
学分绩点 = 内置示例规则垫底（绩点 =（成绩−50）÷10，明确标「示例」）；同时请用户上传本校《学生手册》，拿到原文就按原文替换
```

**教师评分规则要能复用**：出勤 / 作业 / 实验 / 课程设计各自占比因老师而异，存成模板（如「王老师·高等数学：期末 60%，出勤 20，作业 30，期末小测 50」），下次同老师的课一键套用，已填的同名条目分数保留。

### 第三步 · 收材料（档案）

奖状、证书、讲座打卡、志愿服务记录 → **先存原图/原文，再匹配，再确认**：

1. 按材料类型抽关键信息（竞赛级别 / 获奖等级 / 队内排序 / 体测等次 / 干部考核等次 / 荣誉级别…）；
2. 按细则算「建议分 + 归属板块 + 条款坐标 + 计算过程」；
3. **「待核」不计分**（讲座、志愿服务、论文这类细则没结构化的项），用户手动填分并写条款坐标，确认后才计入；
4. 确认为「确定」后，才允许同步进综测账本对应板块，记差额防重复。

### 第四步 · 算账（用脚本，别心算）

```bash
python scripts/cross_system.py                  # 跨体系对比：同一件事两个分
python scripts/zongce_ledger.py --demo
python scripts/zongce_ledger.py zongce.json
python scripts/credit_ledger.py --demo
python scripts/credit_ledger.py ledger.json taken.json
python scripts/gpa_ledger.py --demo             # 绩点账：期末+平时两层加权
python scripts/gpa_ledger.py gpa.json --term 3       # 只看第 3 学期
python scripts/gpa_ledger.py --demo --rule sample    # 附带示例 GPA（明确标注示例）
```

四个脚本**只做加权求和、查表与差额计算**，零第三方依赖（只用 json/re/sys）。

`gpa.json` 格式：
```json
{"courses": [{"name": "高等数学 A", "credit": 5, "term": 1, "final": 86, "finalW": 60,
  "comps": [{"name": "出勤", "weight": 20, "score": 95},
            {"name": "作业", "weight": 30, "score": 88}]}]}
```
输出逐门课程成绩 + 加权平均 + 分学期汇总；**缺期末或平时明细的课不计入**（列出原因），GPA 一律显示「待学校换算规则」。

### 第五步 · 排任务

把四块账合成**一份**清单，每条带「依据 + 不做的后果 + 截止」。粒度是**学期**，不是每天。

## 四板块与五大模块（口径）

综测细则第五条原文：**德、智、体、美、劳五个方面**，并**单设**学术科技与创新创业能力附加分项。

```
综测成绩 = 德育×10% + 智育×70% + 体育×10% + 美育×5% + 劳动教育×5%
          + 学术科技与创新创业（≤20，不乘权重） − 扣分
```

| 板块 | 挣 1 分子分，总分涨 |
|---|---|
| **学术科技与创新创业** | **1.0 分**（直连） |
| 智育（绩点那栏） | 0.7 分 |
| 德育 / 体育 | 0.1 分 |
| 美育 / 劳动教育 | 0.05 分 |

**同样是努力，效率差 10 倍。** 而学分那头相反：**漏一门顺延一学期，不可补救**。

## 四条铁律

1. **必须溯源**：每条数据带原文坐标（页码/条款号/附件表名）。**核不到就留空，不编坐标。**
2. **不做加法以外的推断**：文件没写的（课程难度、获奖概率、老师水平）一律不答。
3. **数字必须逐字来自原文**：原文写 2.5 就写 2.5。
4. **文件打架就说打架**：正文与分项加总不符、同一件事两个文件规定不同，**两个数都报出来**，指出去哪里问，**不替它抹平**。

## 已知边界（写在明面上）

| 边界 | 事实 |
|---|---|
| 绩点换算 | 培养方案全文 0 次提「绩点/GPA/成绩」；默认用内置**示例规则**并标注「示例」，同时引导用户上传《学生手册》/学籍管理规定，拿到原文按原文替换 |
| 扫描件 PDF | 图片型扫描件抽不出文字，**要用户粘贴或重拍**，不猜 |
| 课程表 | 只认表格结构；跨页断行的课程可能漏，**导入前逐条列给用户看** |
| 讲座 / 志愿服务 / 论文 | 细则未结构化到单场/单篇，**一律待核计 0** |
| 多学期课程 | 「形势与政策」在第 1/4/5/7 学期都开，导入按首个学期落，**其余学期需用户手动补** |

## 已核出的两处真实矛盾（照实呈现，不抹平）

1. **培养方案选修加总超标**：第 4 页声明「选修 24 学分」，但各模块相加 = 28（必修 126 完全一致）
2. **高阶挑战课程**：学分要求写「必修 0、选修 0」，其下仍列了 3 学分的课程

另外**综测与推免的竞赛分级口径不同**：综测六级直接给分，推免四类乘系数——不是矛盾，但**同一场比赛两边查表方式不一样**，必须分别查。

## 常见坑

| 坑 | 表现 | 处理 |
|---|---|---|
| 拿 GPA 当综测智育 | 用绩点乘 70% 算总分 | 综测用加权平均分，绩点另列 |
| 漏了单设项 | 只算五育，总分少 20 分 | 学术科技单独成块 |
| 分级串台 | 拿综测的六级表去查推免分 | 两套表分开 |
| 出勤表混入 | 「赛事一等奖15分/出勤率≥100%」被当综测加分 | 那是第二课堂，剔除 |
| 学分单元格脏写 | PDF 里 `2.5` 被抽成 `25\n.` | 去掉换行后按小数点位置还原 |
| 同一门课多个名字 | 「形势与政策」在表里出现 4 次 | 按学期拆多条 |
| 多个版本 | 2024/2025/2026 级要求不同 | **先问清是哪一级** |
| 论文/竞赛权重混用 | 拿「第四作者不加分」套到学科竞赛 | 竞赛按 `÷[1+(排序−1)×0.5]` 取前 8 人；0.5/0.3/第四起 0 只属于论文（细则第六条（一）注①） |
| 国创赛/挑战杯国赛 ×1.5 | 问「挑战杯国赛金奖推免加多少」按 50 答就少了 | 原文：国创赛/挑战杯国家级奖励按同级别 **×1.5** 后在限定分内加分（推免附件（一）4）。**脚本不自动乘** |

## 交互原则

1. **先确认年级与学年**（要求不同）
2. **一次只问一个必要问题**
3. **算不出来明说缺什么**——不填 0、不猜、不计入
4. **每份输出带原文坐标**
5. **排任务前先问「你现在第几学期」**——不知道学期，排出来的任务全是错的
6. **给完清单就停**——不追问「要不要提醒你」

## 隐私与数据边界

1. **全部计算在本机完成**：技能不联网、不上传任何文件、分数或结论；三个脚本只读用户给定的 JSON，零第三方依赖（只用 json/re/sys）。
2. **不把个人数据写进技能目录**：成绩单、综测得分、获奖记录只出现在用户自己的输出文件里。
3. **不连教务系统、不索取账号密码**：需要权限的事一律不做。
4. **输出由用户自留自删**：生成的账本文件放在用户指定位置，删掉即彻底消失。
5. **外发前自行把关**：报告可能含姓名、学号、分数等个人信息。

## 不做什么

| 不做 | 原因 |
|---|---|
| 查成绩、连教务系统 | 需要账号权限，不合规 |
| 评价课程难易、老师水平 | 文件里没有，属于编造 |
| 猜获奖概率 | 没有往年数据，猜就是编 |
| 承诺"照这个修就能毕业" | 认定权在教务处 |
| 预测保研结果 | 名额与排名由学院决定 |
| **主动推送消息 / 定时提醒** | 主动推送等于再增加一个消息流，正是本作品想逃离的场景 |

## 附带的可视化

`assets/学业记录.html` 是本技能的**单文件可视化账本**（线上演示：https://jicetong-xueye.app.workbuddy.host/学业记录.html?sharecode=R55LQEXORU ），屏幕切换式导航，点卡片进入下一屏，每个子屏左上角有「← 返回」按钮、也可点面包屑返回上一级，Esc 先关弹窗再返回上一级，每屏带来源回溯：

1. **首访建档**：选年级（大一–大四）与入学级（决定培养方案版本）；年级影响体育课等部分口径，改年级会按新口径重算。首访一律从空白起步（只保留细则给的基础分，总分 14.5、无课程无材料），不会拿演示数据冒充用户数据；样例须显式载入（建档窗「用样例数据开始 →」或首页「载入样例数据」），演示场景用 URL 加 `#demo=1`。
2. **首页 · 总分置顶**：综测总分 64px 置顶，右侧一行效率对比（学术科技 ×1.0 / 绩点 ×0.7 / 德育·体育 ×0.1 / 美育·劳育 ×0.05）；顶栏 sticky 导入区支持拖拽文件（txt 直接存档并抽文字，PDF/图片登记名称留档）。
3. **六块入口**：绩点 + 德育 / 体育 / 美育 / 劳动教育四块 + 学术科技单设卡（细则：不进五育加权），点任一块进入条目级计分。
4. **绩点三级下钻**：绩点 → 课程列表 → 单门课「平时分 / 期末分」两板块；顶部可粘贴解析自动抽平时构成与期末权重，解析后手动填分；底部课程成绩算式照抄。GPA 用内置示例规则并标「示例」，附上传《学生手册》按原文替换的引导。
5. **模块条目计分**：按细则真口径（德育 = 基础分（自填，上限 75）+ 附加分封顶 25；美育 = 基础分（自填 0–80）+ 附加分 20；劳育 = 基础分（自填 0–60）+ 附加分 40；体育 = 体测 40 + 体育课 40 + 活动 20（无基础分）；学术科技封顶 20）。**基础分不预置、默认 0**——按原文「达标/评到多少才得多少」自己填，不默认白送；每条目可直接键盘输入并点「来源」回看条款坐标与原文，模块底部「✓ 确认本模块分数」写档。
6. **侧层**：学分明细（16 模块 + 两处矛盾）、综测档案袋（建档 + 归档 + 细则匹配 + 确认 + 同步账本 + 导出 zip）、原文依据（综测细则与推免办法全文内嵌在 HTML 里，离线可查；从任一条目的「来源」点「打开原文」会跳到对应那一句并高亮，不是只印文件名的假溯源）。
7. **两套主题**：青灰（默认）/ 暗黑，顶栏 ◐ 一键切换。

**它是展示与人工记账界面，不是提交物本体。**

## 自检（三态对账）

四个脚本都能自证算得对，任一条不过即非 0 退出（合计 **115 条**）：

```bash
python scripts/cross_system.py   --self-check   # 36 条：正常 / 边界 / 数据完整性
python scripts/zongce_ledger.py --self-check   # 28 条：公式 / 边界 / 数据完整性
python scripts/credit_ledger.py --self-check   # 26 条：匹配 / 边界 / 数据完整性
python scripts/gpa_ledger.py    --self-check   # 25 条：两层加权 / 缺项 / 舍入一致性 / 示例 GPA
```

- **正常**：已知原文数值的用例（省甲类一等奖综测 10 分、推免 A1 全国一等奖 50 分）
- **边界**：查不到、第 4 名、空成绩单——必须返回「不知道」而不是编一个数
- **数据完整性**：常量表与原文一致性的硬断言（封顶 20/100、系数 1/0.7/0.5）
- **界面层**：`assets/学业记录.html` 的 61 项交互断言（jsdom 真实点击，含顶部导入区、总分置顶、绩点三级下钻、细则基础分+附加封顶、档案袋建档→匹配→同步→总分联动、zip crc32 与 Node zlib 对拍），见 `references/自检与复跑.md`
