## 〇、先说清「一周点击和点赞」这件事

**问：上传后能统计「一周以来的点击次数和点赞数量」吗？**

2. GitHub 官方：流量数据（访问量 / 独立访客 / 完整克隆）**只保留最近 14 天**，且只有具备 push 权限的人能看；`traffic/views` 与 `traffic/clones` 两个 API 无论按天还是按周请求，都只返回最近 14 天。

**问：那要达到你的目的，怎么做？**

1. **今天建立基线**：仓库建好、README 写完，把当前 star / fork / watch 数记下来（大概率全 0）。
2. **7 天后抓一次真实数据**：Views、Unique visitors、Clones、Stars，出一份「首周数据报告」。再往后每周同一时间抓，因为 14 天窗口会滚动覆盖，不能事后补。

## 三、翼测通的优缺点（对照上述 6 个）

**问：优点（相对同类）在哪？**
答：
1. **跨体系对比是独一份**。6 个对照组全部只算一套分；你们把综测、推免、学分三套并列，并指出「省甲一等奖综测 10 分、推免 20~50 分，差 5 倍」。
2. **可点开的溯源**。别人的结果是黑箱，你们的每条分值带条款号，点「来源」跳内嵌原文并高亮到具体那一行。
3. **从 PDF 抽规则而非只抽成绩**。最接近的 `VIT-GPA-Calculator` 只从 PDF 抽课程表；你们从培养方案抽 103 门课、从细则抽加分公式、从推免办法抽八类加分。
4. **零依赖 + 数据不出本机**。4 个脚本只用 `json/re/sys`，单 HTML 离线可跑——这是同类里几乎没人写的卖点。
5. **诚实状态机**。「待核计 0」「算不出来就说不知道」「文件矛盾照实并列」——这是竞品普遍没有的纪律。

**问：缺点（相对同类）在哪？**
答：
1. **没有公开页面，第一眼看不到东西**。6 个对照组全是网页或 App，点开就能用；你们交的是 Skill 包 + 单 HTML，GitHub 上不打开 HTML 就只剩一堆文字。**这是最大的获客短板**。
2. **没有英文摘要**。GitHub 全球流量，中文 README 会把 90% 的潜在访客挡在门外。
3. **没有 LICENSE**。无许可证 = 默认禁止他人使用/修改，对开源项目是硬伤。
4. **演示是静态截图，无 GIF / 视频**。竞品 README 普遍带截图，头部项目带动图。
5. **本机绝对路径泄露隐私**。`references/自检与复跑.md` 里写着 `C:/Users/宋鹤眠/...`，上传前必须改成相对路径。
6. **零真实用户、零 star、零 follower**。客观起点，不装作有。

## 四、改进建议（按优先级）

**问：上传前必须做什么？**
答：
1. **清本机路径**：`自检与复跑.md` 里的 `C:/Users/宋鹤眠/...` 改成 `python -m ...` 或 `<你的 python 路径>`。
2. **加 LICENSE**：建议 MIT，一行声明即可。
3. **加英文 README 段**：开头 5 行英文摘要（问题 / 做法 / 差异 / 技术 / 隐私），后面中文详述。
4. **加一张 GIF 或 3 张截图**：把「点来源 → 跳原文 → 高亮条款」这三步做成动图，这是你们最有说服力的画面。
5. **加 `.gitignore`**：排除 `*.bak`、 `__pycache__/`、个人数据文件。

**问：仓库结构上怎么放？**
答：建议 `skill/` 放 11 个提交文件原样，`docs/` 放说明文档与答辩稿，`assets/` 放截图。顶层 README 直接写清楚「怎么装、怎么 @ 调用、哪些文件能读、哪些不做」。

**问：Topics（标签）怎么填？**
答：`education` `gpa` `chinese-university` `agent-skill` `teleagent` `transcript-parser` `privacy-first` —— 前三个吃搜索流量，后四个定差异。

**问：怎么让第一周不止 0 访问？**
答：GitHub 本身不导流。新账号 0 粉丝，必须靠站外带人：发重邮相关 QQ 群、把 README 链接贴到答辩材料末尾、在 CSDN / 掘金写一篇「把综测细则读成可核验的账」。**不要指望放上去就有人来。**

**问：要不要现在就建定时任务抓数据？**
答：建议建——每周抓一次 Views / Visitors / Clones / Stars 存成本地 CSV。因为 GitHub 只留 14 天，不抓就永久丢失。但这属于新增自动化任务，按你的规矩我自己不拍板，等你确认。
