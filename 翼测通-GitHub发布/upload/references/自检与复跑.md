## 四、非法输入容错实测（2026-10-25，10 个场景）

| # | 场景 | 输入 | 实际行为 | 结论 |
|---|---|---|---|---|
| 1 | 分值是字符串 | `"de": "abc"` | 归 0，照常出报告 | 不猜、按 0 |
| 2 | 分值 null / 空串 | `"mei": null`、`"lao": ""` | 归 0 | 同上 |
| 3 | 负值 | `"zhi": -5` | 照算，不裁 | 输入责任在调用方；UI 输入框 `min=0` 无此入口 |
| 4 | 超上限 | `"xs": 1000000000000` | 照算不裁（总分 1e12+96.4） | **已知边界**：脚本不做上限裁剪；UI 超上限会标红 |
| 5 | deduct 给成 list | `["警告处分", 1]` | 友好提示正确格式 | 2026-10-25 修复（原为 AttributeError traceback） |
| 6 | 非 JSON 文件 | 坏 JSON | 友好提示出错行列 | 2026-10-25 修复（原为 traceback） |
| 7 | 文件不存在 | `nope.json` | 友好提示路径 | 2026-10-25 修复（原为 traceback） |
| 8 | `--term` 非数字 | `--term abc` | 友好提示用法示例 | 原有行为 |
| 9 | `--term` 越界 | `--term 99`（总学期 8） | 照排并标注「第 99 学期」，不警告 | **已知边界**：学期号由调用方负责 |
| 10 | 空 JSON | `{}` | 不排任务，明说需要学期号 | 诚实降级：不知道学期，排出来的任务全是错的 |

修复只动了两个脚本 `main()` 的读入层（try/except + 类型检查），`compute`/`report`/`--self-check` 逻辑零改动——修复后重跑三态自检仍为 36/28/26。
