# 绩点与平时分口径

技能在「录课程」阶段参考本文件。

---

## 一、三层算法（都是可验算的算术，没有黑箱）

```
平时分   = ∑(条目得分 × 条目权重) ÷ ∑条目权重
课程成绩 = 期末分 × 期末权重% + 平时分 × (1 − 期末权重%)
加权平均 = ∑(课程成绩 × 学分) ÷ ∑学分
```

**为什么权重不用凑满 100**：老师给的规则常是「出勤 20、作业 30、实验 20、项目 30」，也可能写成 2:3:2:3。按 **Σ得分×权重 ÷ Σ权重** 归一，两种写法算出来一样，用户不必自己折算。

**缺一项就待填，不要补 0**：期末分没填或平时条目一条都没有时，课程成绩返回空，界面上显示「待填」，**不参与加权平均**。补 0 会把平均分拉低，是错误而不是保守。

**示例（可手算核对）**

| 课程 | 学分 | 期末 | 期末权重 | 平时条目 | 平时分 | 课程成绩 |
|---|---|---|---|---|---|---|
| 高等数学 A | 5 | 86 | 60% | 出勤 20/95、作业 30/88、期末小测 50/84 | 87.4 | 86×0.6 + 87.4×0.4 = **86.56 → 86.6** |
| 大学英语 | 4 | 90 | 50% | 出勤 20/96、作业 40/90、口语 40/88 | 90.4 | 90×0.5 + 90.4×0.5 = **90.2** |

加权平均 = (86.6×5 + 90.2×4) ÷ 9 = 88.2

## 二、加权平均分 ≠ 绩点（GPA）

| 口径 | 公式 | 用途 | 依据 |
|---|---|---|---|
| 加权平均分 | `∑(课程成绩×学分) ÷ ∑学分` | **综测**的智育（×70%） | 《综合素质测评实施细则》（二）原文 |
| 学分绩点 GPA | 由学校换算规则定（4.0 制 / 5 分制 / 等级制课程折算…） | 学业成绩单、部分推免门槛 | 各校《学生手册》或学籍管理规定 |

**这两列必须并排显示、各标用途。** 拿 GPA 去乘 70% 是口径错误——GPA 一般 1.0–5.0，乘出来只有 3 分级，会把总分算塌。

**没有原文就只给「示例」。** 已核对：重庆邮电大学智能科学与技术培养方案全文 13 页，**「绩点 / GPA / 学分绩点 / 平均学分绩点 / 成绩」出现 0 次**，只有 13 处「考核」（课程的考核方式）——换算规则不在这份文件里。处理办法：

1. 界面用内置**示例规则**（绩点 =（课程成绩−50）÷10，60 分以下计 0）算出演示值，**明确标注「示例」**，绝不冒充学校原文；
2. 同屏写明引导：把本校《学生手册》里的〈平均学分绩点计算办法〉发给冀测通；
3. 拿到原文后按原文写死公式，并在界面标注条款出处，替换掉示例。

> 若用户提供了规则文件：把公式写进脚本常量 + 页面文案，并加一条自检断言（如 90 分对应 4.0 / 4.0 制），**不要凭印象写**。

## 三、教师评分规则要能复用

同一门课不同老师给分构成不同，规则本身是**数据**，不是代码：

```json
{"id":"r1","name":"王老师 · 高等数学","finalW":60,
 "comps":[{"name":"出勤","weight":20},{"name":"作业","weight":30},{"name":"期末小测","weight":50}]}
```

- 模板只存 **条目名 + 权重 + 期末权重**，不存分数；
- 套用模板时，**同名条目保留用户已填的分数**（避免重复录入）；
- 模板可改名、可删；删除模板不影响已套用的课程（课程里存的是副本）。

## 四、学期与年级的映射

| 开课学期 | 年级 | 上/下 |
|---|---|---|
| 1 | 大一 | 上学期 |
| 2 | 大一 | 下学期 |
| 3–4 | 大二 | 上 / 下 |
| 5–6 | 大三 | 上 / 下 |
| 7–8 | 大四 | 上 / 下 |

**多学期课程**（如「形势与政策」在第 1/4/5/7 学期都开）导入时按**首个学期**落，其余学期要用户手动补——不要自动复制成四条，那会虚增学分。

## 五、边界

| 情况 | 处理 |
|---|---|
| 期末分或平时明细缺失 | 课程成绩「待填」，不计入加权平均 |
| 学分 ≤ 0 | 不计入加权平均（但仍保留在课程表里） |
| 期末权重 > 100 或 < 0 | 夹到 0–100，界面不静默修正数值以外的行为 |
| 等级制课程（优秀/良好/合格） | **没有换算规则就不换算**，让用户按学校规定折算成百分制后再录 |
| 重修 / 补考 | 尊重用户录入的最终成绩；不自动替换旧成绩（细则口径各校不同） |
